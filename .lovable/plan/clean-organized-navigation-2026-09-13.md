# Clean, Organized Navigation

## Goal
Make the header easier to scan, better aligned, and less crowded without removing access to any current page.

## Changes
- Replace the long row of individual links with a compact primary navigation: Home, Programmes, Explore, Resources, and Locations.
- Make Locations a single direct link to the campus directory instead of a city dropdown.
- Group related pages logically:
  - Programmes: Departments, SIWES / IT, Virtual SIWES, Success Kit
  - Explore: Careers, Opportunities, Events, Tech Hubs
  - Resources: Blog, Products, Tech Store, Partnerships
- Keep About as a simple secondary link where space allows.
- Preserve the currency control, account/dashboard actions, and sign-up action.
- Rework the mobile menu into clearly labelled sections with consistent spacing and active-page highlighting.
- Improve desktop spacing, dropdown widths, header alignment, focus states, and small-screen behavior using the existing visual system.

## Verification
- Check desktop and mobile layouts for overflow, alignment, menu opening, navigation, and active-page states.
- Confirm every existing destination remains accessible and Locations opens `/locations` directly.
